# PRISM — AI-Powered Media Engine

An ultra-modern, high-impact SaaS landing page for **PRISM** – the autonomous AI media engine for creators, broadcast networks, and post-production studios.

Designed with an editorial hairline grid aesthetic (inspired by modern developer-first platforms), dark theme (`#000000`), glassmorphism, procedural canvas soundwaves, interactive aspect ratio sandbox, prompt terminal, and dynamic pricing switcher.

## 🚀 Live Demo & Tech Stack
- **HTML5 & Vanilla CSS3**: Custom design tokens, glassmorphism, 1px precision hairline borders.
- **Vanilla ES6 JavaScript**: Procedural Canvas audio spectrum, dynamic aspect ratio sandbox, real-time counters, interactive terminal.
- **Lucide Icons & Google Fonts**: Plus Jakarta Sans, Inter, JetBrains Mono.
